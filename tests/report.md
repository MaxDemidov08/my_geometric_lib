# Тестирование

## 1. Цели и задачи тестирования

Целью тестирования является проверка корректности работы программных модулей, реализующих вычисление площади и периметра геометрических фигур.

## 2. Описание тестируемого продукта

Тестируемый программный продукт представляет собой библиотеку геометрических вычислений, разработанную на языке Python в ходе предыдущих лабораторных работ.

Библиотека состоит из четырёх модулей:

- `circle.py` — вычисление площади и периметра круга.
- `square.py` — вычисление площади и периметра квадрата.
- `rectangle.py` — вычисление площади и периметра прямоугольника.
- `triangle.py` — вычисление площади и периметра треугольника.

Каждый модуль содержит две функции:

- `area()` — вычисление площади геометрической фигуры.
- `perimeter()` — вычисление периметра геометрической фигуры.

Функции принимают числовые параметры, соответствующие геометрическим характеристикам фигур, и возвращают результаты вычислений.

## 3. Область тестирования

Область тестирования включает проверку функций вычисления площади и периметра всех четырёх геометрических фигур.

Тестированию подлежат следующие функции:

| Модуль | Функция | Назначение |
|---|---|---|
| `circle.py` | `area(r)` | Вычисление площади круга |
| `circle.py` | `perimeter(r)` | Вычисление длины окружности |
| `square.py` | `area(a)` | Вычисление площади квадрата |
| `square.py` | `perimeter(a)` | Вычисление периметра квадрата |
| `rectangle.py` | `area(a, b)` | Вычисление площади прямоугольника |
| `rectangle.py` | `perimeter(a, b)` | Вычисление периметра прямоугольника |
| `triangle.py` | `area(a, h)` | Вычисление площади треугольника |
| `triangle.py` | `perimeter(a, b, c)` | Вычисление периметра треугольника |

Для каждой функции разработано по два теста, проверяющих:

1. Корректность вычислений при неотрицательных входных значениях.
2. Корректность вычислений при передаче нулевых значений.

Таким образом, общее количество разработанных тестов составляет **16**.

## 4. Стратегия тестирования

Для проверки корректности работы библиотеки применяется модульное тестирование (Unit Testing).

Тестирование осуществляется с использованием стандартной библиотеки Python `unittest`.

Выбран метод функционального тестирования по принципу «чёрного ящика», при котором проверяется соответствие результатов выполнения функций ожидаемым значениям без анализа их внутренней реализации.

Для проведения тестирования создан отдельный файл `test_geometry_lib.py`, содержащий четыре тестовых класса:

- `CircleTestCase` — тестирование функций круга.
- `SquareTestCase` — тестирование функций квадрата.
- `RectangleTestCase` — тестирование функций прямоугольника.
- `TriangleTestCase` — тестирование функций треугольника.

Каждый класс наследуется от `unittest.TestCase` и содержит четыре тестовых метода.

Для проверки результатов используется метод:

```python
self.assertEqual(actual, expected)
```

Если значения совпадают, тест считается успешно пройденным. В противном случае фиксируется ошибка тестирования.

Для проверки функций выбраны два типа входных данных:

**1. Неотрицательные значения**

Позволяют проверить правильность вычислений при стандартных условиях использования программы.

**2. Нулевые значения**

Позволяют проверить поведение функций в граничных случаях, когда один или несколько входных параметров равны нулю.

Для запуска тестирования используется команда:

```bash
python -m unittest tests/test_geometry_lib.py
```

Исходный код тестируемых модулей в процессе выполнения лабораторной работы не изменяется.

## 5. Критерии приёмки

Основным критерием успешного прохождения тестирования является соответствие фактических результатов вычислений математически ожидаемым значениям.

Для каждого теста определены входные параметры и ожидаемый результат.

| № | Тест | Входные данные | Ожидаемый результат |
|---|---|---|---|
| 1 | Площадь круга | r = 5 | 25π |
| 2 | Периметр круга | r = 13 | 26π |
| 3 | Площадь круга при нулевом радиусе | r = 0 | 0 |
| 4 | Периметр круга при нулевом радиусе | r = 0 | 0 |
| 5 | Площадь квадрата | a = 5 | 25 |
| 6 | Периметр квадрата | a = 5 | 20 |
| 7 | Площадь квадрата при нулевой стороне | a = 0 | 0 |
| 8 | Периметр квадрата при нулевой стороне | a = 0 | 0 |
| 9 | Площадь прямоугольника | a = 5, b = 10 | 50 |
| 10 | Периметр прямоугольника | a = 5, b = 10 | 30 |
| 11 | Площадь прямоугольника при нулевой стороне | a = 0, b = 10 | 0 |
| 12 | Периметр прямоугольника при нулевых сторонах | a = 0, b = 0 | 0 |
| 13 | Площадь треугольника | a = 3, h = 4 | 6 |
| 14 | Периметр треугольника | a = 3, b = 10, c = 2 | 15 |
| 15 | Площадь треугольника при нулевой высоте | a = 5, h = 0 | 0 |
| 16 | Периметр треугольника при нулевых сторонах | a = 0, b = 0, c = 0 | 0 |

Тест считается успешно пройденным, если возвращаемое функцией значение совпадает с ожидаемым.

При обнаружении несоответствий тест считается проваленным, а выявленная проблема фиксируется для последующего анализа.

## 6. Ожидаемые результаты тестирования

В результате проведения модульного тестирования предполагается получить информацию о корректности работы всех функций библиотеки геометрических вычислений.

Ожидаемые результаты:

1. Успешное обнаружение и выполнение всех 16 разработанных тестов.
2. Подтверждение правильности вычисления площади и периметра геометрических фигур при положительных входных значениях.
3. Проверка поведения функций при передаче нулевых параметров.
4. Выявление возможных несоответствий между фактическими и ожидаемыми результатами.

При успешном прохождении всех тестов ожидается следующий итоговый вывод:

```text
................
----------------------------------------------------------------------
Ran 16 tests in <time>s

OK
```

Время выполнения(<time>) может отличаться в зависимости от используемого оборудования.

В случае обнаружения ошибок библиотека `unittest` должна вывести информацию о проваленных тестах с указанием ожидаемых и фактических значений.
