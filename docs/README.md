# Общее описание проекта: geometric_lib

Данный проект представляет собой набор модулей для расчета геометрических параметров различных фигур и преобразований чисел. (площадь и периметр/длина окружности | вычисление квадрата числа).

В состав решения входят следующие файлы:
1. `rectangle.py` - функции для прямоугольника.
2. `circle.py` - функции для круга.
3. `square.py` - функции для квадрата.
4. `triangle.py` - функции для треугольника.
5. `count_square.py` - функция для вычисления квадрата.

## Описание функций с примерами вызова

### 1. Прямоугольник (rectangle.py)
* **`area(a, b)`**
    * **Описание:** Принимает длины двух смежных сторон прямоугольника и возвращает его площадь.
    * **Пример вызова:**
    ```py
    print(area(3, 4))  # Выведет: 12.0
    ```
* **`perimeter(a, b)`**
    * **Описание:** Принимает длины двух смежных сторон прямоугольника и возвращает его периметр.
    * **Пример вызова:**
    ```py
    print(perimeter(3, 4))  # Выведет: 14.0
    ```

### 2. Круг (circle.py)
* **`area(r)`**
    * **Описание:** Принимает радиус круга и возвращает его площадь.
    * **Пример вызова:**
    ```py
    print(area(5))  # Выведет: 78.5398
    ```
* **`perimeter(r)`**
    * **Описание:** Принимает радиус круга и возвращает длину окружности.
    * **Пример вызова:**
    ```py
    print(perimeter(5))  # Выведет: 31.4159
    ```

### 3. Квадрат (square.py)
* **`area(a)`**
    * **Описание:** Принимает длину стороны квадрата и возвращает его площадь.
    * **Пример вызова:**
    ```py
    print(area(5))  # Выведет: 25.0
    ```
* **`perimeter(a)`**
    * **Описание:** Принимает длину стороны квадрата и возвращает его периметр.
    * **Пример вызова:**
    ```py
    print(perimeter(5))  # Выведет: 20.0
    ```

### 4. Треугольник (triangle.py)
* **`area(a, h)`**
    * **Описание:** Принимает длину основания и высоту, опущенную на это основание, возвращает площадь треугольника.
    * **Пример вызова:**
    ```py
    print(area(3, 4))  # Выведет: 6.0
    ```
* **`perimeter(a, b, c)`**
    * **Описание:** Принимает длины трех сторон треугольника и возвращает его периметр.
    * **Пример вызова:**
    ```py
    print(perimeter(3, 4, 5))  # Выведет: 12.0
    ```

### 5. Вичисление квадрата числа (count_square.py)
* **`square(n)`**
    * **Описание:** Принимает число n и возвращает квадрат числа n.
    * **Пример вызова:**
    ```py
    print(square(2)) # Выведет: 4.0
    ```
