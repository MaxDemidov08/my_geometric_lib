# Общее описание проекта: geometric_lib

Данный проект представляет собой набор файлов для расчета геометрических параметров различных фигур и преобразований чисел. (площадь и периметр/длина окружности | вычисление квадрата числа).

В решение входят следующие файлы:
1. `rectangle.py` - функции для прямоугольника.
2. `circle.py` - функции для круга.
3. `square.py` - функции для квадрата.
4. `triangle.py` - функции для треугольника.
5. `count_square.py` - функция для вычисления квадрата.

## Описание функций с примерами вызова

### 1. Прямоугольник (rectangle.py)
* **`area(params)`**
    * **Описание:** Принимает список длин смежных сторон прямоугольника `params = [a, b]` и возвращает его площадь.
    * **Пример вызова:**
    ```py
    params = [3, 4]
    print(area(3, 4))  # Выведет: 12.0
    ```
* **`perimeter(params)`**
    * **Описание:** Принимает список длин смежных сторон прямоугольника `params = [a, b]` и возвращает его периметр.
    * **Пример вызова:**
    ```py
    params = [3, 4]
    print(params)  # Выведет: 14.0
    ```

### 2. Круг (circle.py)
* **`area(r)`**
    * **Описание:** Принимает радиус круга `(r)` и возвращает его площадь.
    * **Пример вызова:**
    ```py
    print(area(5))  # Выведет: 78.5398
    ```
* **`perimeter(r)`**
    * **Описание:** Принимает радиус круга `(r)` и возвращает длину окружности.
    * **Пример вызова:**
    ```py
    print(perimeter(5))  # Выведет: 31.4159
    ```

### 3. Квадрат (square.py)
* **`area(a)`**
    * **Описание:** Принимает длину стороны квадрата `(a)` и возвращает его площадь.
    * **Пример вызова:**
    ```py
    print(area(5))  # Выведет: 25.0
    ```
* **`perimeter(a)`**
    * **Описание:** Принимает длину стороны `(a)` квадрата и возвращает его периметр.
    * **Пример вызова:**
    ```py
    print(perimeter(5))  # Выведет: 20.0
    ```

*   **`area(params)`**
    *   **Описание:** Принимает список `params = [a, h]`, где `a` — длина основания, а `h` — высота, опущенная на это основание. Возвращает площадь треугольника.
    *   **Пример вызова:**
    ```python
    params = [3, 4]  
    print(area(params))  # Выведет: 6.0
    ```
*   **`perimeter(params)`**
    *   **Описание:** Принимает список длин сторон треугольника `params = [a, b, c]`.

    | Имя переменной | Описание |
    | :---: | :---: |
    | `a` | длина первой стороны |
    | `b` | длина второй стороны |
    | `c` | длина третей стороны |

Возвращает периметр треугольника.


### 5. Вичисление квадрата числа (count_square.py)
* **`square(n)`**
    * **Описание:** Принимает число `(n)` и возвращает квадрат числа n.
    * **Пример вызова:**
    ```py
    print(square(2)) # Выведет: 4.0
    ```
